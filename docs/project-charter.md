# Project charter

## Purpose

Explore PHP MVC fundamentals, routing, configuration loading, PDO-style model access, templates, and a lightweight Vue integration without a full framework.

## Verified current scope

- Custom router, controller, model, view, error, and configuration classes.
- One home controller/view route.
- Template variants using Bootstrap or Vue via CDN.
- Sample SQL schema and local Docker Compose services.

## Outside scope

- A complete Vue SPA, application domain, authentication, tests, package management, CI, or production framework support.
- Managed secrets, hardened database administration, and deployment operations.

## Portfolio decision

Classify as a learning/reference archive candidate. It provides historical framework-fundamentals context but should not appear in the primary showcase.
