## Status

The repository is a compact custom PHP MVC framework experiment: a router, controller/model/view base classes, environment loading, one home route, optional Bootstrap/Vue templates, and a local Docker/MySQL/phpMyAdmin setup. It is not a complete application or a production framework.

Tracked local database/admin configuration must be remediated separately before any reuse. Retain only as an archive/reference candidate.
